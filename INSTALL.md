# Tawali (طوالي) — Installation Guide

## Prerequisites

| Tool | Version | Download |
|:-----|:--------|:---------|
| **Flutter** | 3.44+ | [flutter.dev](https://flutter.dev/docs/get-started/install) |
| **Dart** | 3.12+ | Bundled with Flutter |
| **Firebase CLI** | Latest | `npm install -g firebase-tools` |

| **Android Studio** | Hedgehog+ | [developer.android.com/studio](https://developer.android.com/studio) |

| **Git** | 2.x+ | `apt install git` / [git-scm.com](https://git-scm.com) |

## 1. Clone the Repository

```bash
git clone https://github.com/Mualimx-Agent/tawali.git
cd tawali/app/tawali_app
```

---

## 2. Firebase Project Setup

### 2.1 Create Firebase Project
1. Go to [firebase.google.com](https://firebase.google.com)
2. Click **Get started** → **Add project**
3. Enter project name (e.g., `tawali-sudan`)
4. Disable Google Analytics (optional)
5. Click **Create project**

### 2.2 Register Android App
1. In Firebase Console → Project Settings → **Add app** → **Android**
2. Android package name: `com.mualimx.tawali`
3. App nickname: `Tawali (طوالي)`
4. Download `google-services.json`

### 2.3 Place Config Files
```bash
# Android
cp ~/Downloads/google-services.json android/app/google-services.json

# iOS (if applicable)
cp ~/Downloads/GoogleService-Info.plist ios/Runner/GoogleService-Info.plist
```

### 2.4 Run FlutterFire Configuration
```bash
# Login to Firebase
firebase login

# List projects
firebase projects:list

# Configure FlutterFire (generates firebase_options.dart)
flutterfire configure --project=your-project-id
```

---

## 3. Enable Firebase Services

### Authentication (Phone OTP)
1. Firebase Console → **Authentication** → **Sign-in method**
2. Enable **Phone** provider
3. Configure SMS verification (test numbers available in Firebase Console)

### Firestore Database
1. Firebase Console → **Firestore Database** → **Create database**
2. Choose location (recommended: `eur3` - Europe for Sudan users)
3. Start in **test mode** (update rules later - see [SECURITY.md](SECURITY.md))
4. Click **Enable**

### Firebase Storage
1. Firebase Console → **Storage** → **Get started**
2. Choose location (same as Firestore)
3. Start in **test mode**
4. Click **Done**

### Firebase Cloud Messaging
1. Firebase Console → **Cloud Messaging**
2. Ensure Cloud Messaging API is enabled
3. Note the **Server Key** for server-side notifications

## 4. Install Dependencies

```bash
# Get Flutter packages
flutter pub get

# Verify everything compiles
flutter analyze
```

---

## 5. Build & Run

### Development
```bash
# Run on connected device / emulator
flutter run

# Run in debug mode with specific device
flutter run -d <device_id>

# List available devices
flutter devices
```

### Release Builds
```bash
# Android APK
flutter build apk --release

# Android App Bundle (recommended for Play Store)
flutter build appbundle --release

# iOS (macOS only)
flutter build ios --release

# Web
flutter build web --release
```

### Generated Files
```
app/tawali_app/build/
├── app/outputs/flutter-apk/app-release.apk    (APK)
└── app/outputs/bundle/release/app-release.aab  (AAB)
```

## Troubleshooting

| Issue | Solution |
|:------|:---------|
| `google-services.json not found` | Download from Firebase Console → Project Settings → Android app |
| `flutter pub get` fails | Check internet connection; run `flutter clean` then retry |
| `OTP not sending` | Enable Phone Auth in Firebase Console; verify phone number format (+249...) |
| `Build fails on iOS` | Run `cd ios && pod install && cd ..` |
| `RTL layout broken` | Ensure `Directionality` widget wraps the MaterialApp |
| `Firestore permission denied` | Update Firestore rules (see [SECURITY.md](SECURITY.md)) |
